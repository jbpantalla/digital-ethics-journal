# Ethically Me

*A Journal of Choices, Values, and Moral Dilemmas*, a digital ethics journal by **John Benedict C. Pantalla**.

The journal is one self-contained web page shaped like a leather-bound book. It opens from a closed cover into two-page spreads.

## Open it

Double-click `index.html`, or open it in any modern browser. It works fully offline: there are no external files, fonts, libraries, or network requests.

- My Moral Insight

## How to use it

| Action | How |
|---|---|
| Open or close the book | **Open Journal** on the cover, or **Return to Cover** (Esc also closes) |
| Turn pages | Previous / Next buttons, Left / Right arrow keys, or click an empty area of the left or right page |
| First / last page | Home / End |
| Search | Type in the search box, or press `/` to jump to it. Results highlight the matching text |
| Jump to a section | Click an entry in the Contents list |
| Phone | Swipe left or right to turn pages |

Each page has its own link, for example `index.html#p1-moment-3` (Part 1) or `index.html#moment-3` (Part 2).

## Accessibility

- **Keyboard:** everything works from the keyboard.
- **Screen readers:** the pages use ARIA labels.
- **Progress:** a progress bar shows how far through the journal you are.
- **Reduced motion:** if "reduce motion" is turned on in your system settings, the book opens and turns pages instantly, with no animation.

## Testing

`test-evidence/` holds the test report (`TEST-REPORT.md`) and screenshots. Testing used Chromium at four screen sizes: 1440x900, 1366x680, 768x1024 and 390x844. Safari, Firefox, and swiping on a real phone have not been tested.
